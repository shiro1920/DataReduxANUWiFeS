This is custom code that is used to download, reduce, and post-process astronomical data from ANU2.3m/WiFeS IFU data. Need to download sfddata yourself, it is not included in the code. The data are reduced using the official pipeline pywifes3, which can be downloaded [here](https://github.com/PyWiFeS/pywifes).


sfddata
=======

Dust map data from [Schlegel, Finkbeiner and Davis (1998)](http://adsabs.harvard.edu/abs/1998ApJ...500..525S).

It can be downloaded [here](https://github.com/kbarbary/sfddata).
