This is custom code that is used to download, reduce, and post-process astronomical data from ANU2.3m/WiFeS IFU data. Need to download sfddata by yourself, it is not included in the code.


sfddata
=======

Dust map data from [Schlegel, Finkbeiner and Davis (1998)](http://adsabs.harvard.edu/abs/1998ApJ...500..525S).

It can be download [here](https://github.com/kbarbary/sfddata).
